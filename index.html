Birbal, an ask-your-data assistant

Claude API · Node · Vercel · Supabase Postgres

You ask a question in plain English. It writes read-only SQL, runs it, and hands back the number and the query, so anyone can check it rather than trust it.

The security is the part I care about. It doesn’t live in the prompt, it lives in the database — every question runs under the asker’s own scoped Postgres role. Talk it into anything you like and it still can’t read a table you weren’t granted.

I went through 148 real questions and 346 logged statements and built default query surfaces that killed off each kind of wrong answer one at a time.

The P&L, written in SQL

PostgreSQL · Power BI · Alteryx

Sales register down to EBITDA — material cost, gross margin, yield loss, overhead allocation keys taken from the management MIS — with an absorption check that proves every rupee of cost actually lands somewhere instead of quietly evaporating between two steps.

This is where the find came from. A returns-capping provision for late partner credits turned up a ₹5 crore overstatement of net sales. Nobody went looking for it. Invoiced value and settled value stopped agreeing, and I followed the difference instead of writing it off.

The MIS, common-size and margin-bridge boards all run off this model, and I lead the annual operating plan with scenario templates for outsourcing and pricing calls.

Order-to-cash bridge

PostgreSQL · Power BI

PO to invoice to GRN to credit memo, matched end to end, feeding a live fill-rate board. A missed PO shows up the day it happens, not in the next quarterly review.

It’s also how ₹2.6 crore of apparent Zepto short-credits turned out not to be shortages at all. The goods had arrived; the GRN feed had simply never reported them. A separate 530,000-unit gap traced back to Amazon Fresh being billed through More Retail.

Knowing which half of a shortfall is real is the difference between a claim worth filing and a month spent chasing nothing.

20–25%warehouse losses cut

Marketplace GRN automation

Python · a dozen small repos

Zepto, Reliance, BigBasket, Milkbasket, Hyperpure, More Retail — every one of them publishes goods-receipt notes in its own format, on its own portal, on its own schedule. Each got its own small scraper that pulls them down and turns them into one clean Excel.

It’s the least glamorous thing on this page and none of the rest works without it. The order-to-cash bridge can only match a PO to a receipt if the receipts actually arrive in a consistent shape, and before this they didn’t.

India Card Monitor

Python · D3.js · auto-refreshed

The RBI publishes bank-wise card statistics every month. NPCI publishes UPI data separately. Nobody joins them, so I did — who issues India’s cards, which banks and apps carry UPI, and what a payment is actually worth, month by month since April 2011.

It refreshes itself, so the series keeps extending without me touching it.

Why

Under it

shelf.monitor

Playwright · FastAPI · headless capture

Search rank, share of shelf, sponsored slots, price ladder and stock-outs on Blinkit — by keyword and by pincode. A headless browser sets the delivery location, runs the search and reads Blinkit’s own search API as the page scrolls, so you get the shelf a real shopper in that pincode sees.

Type a search term and a pincode, wait about a minute, get the shelf measured.

Growth Forecaster

R Shiny

Forecast a gross-margin profile from the levers that actually drive it, rather than from one growth percentage applied to last year. Upload a history keyed by date, partner category, supply quantity, MRP, commission, return rate, GST, raw material, packaging and manufacturing cost per unit, and yield loss — then move the levers and watch the P&L respond.

File Merger Pro

R Shiny · v2.0.0

Combine Excel and CSV files into one table. Built for the case everyone in this job knows: the same report arriving as twelve files with twelve slightly different headers.

It can match columns by name or by position, trim and drop blank rows, de-duplicate on the data while ignoring source columns, and stamp each row with the file and sheet it came from — which is the bit you always want an hour later, when a number looks wrong and you need to know where it came in from.

GitHub Actions Monitor

JavaScript · MIT

Cross-repo CI health, flaky failures and compute spend in one place: what’s running now, what’s gone past its usual duration, and which repositories are burning the minutes.

I wrote it because a test that fails once a week is invisible inside any one repository’s run history, and obvious the moment you line every repository up side by side.

Your token is pasted into the sidebar and stays in that browser tab — never stored, never sent anywhere except api.github.com. It opens on generated sample data so you can see what it does before handing it anything.
